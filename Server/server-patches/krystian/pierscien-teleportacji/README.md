# Rozszerzony Pierścień Teleportacji

Autorski quest rozszerzający funkcjonalność Pierścienia Teleportacji o szybkie przenoszenie do kluczowych lokacji.

## Co daje graczowi
- Szybkie skróty do lochów:
  - Loch Pająków V1
  - Trudny, Normalny i Łatwy Loch Małp
- Skróty do nowych krain i map Arezzo:
  - Dolina Cyklopów (mapa 360)
  - Pustkowie Faraona (mapa 361)

## Pliki
- `teleport_ring.quest` – kod źródłowy questu w Lua.

## Instalacja
Skopiuj `teleport_ring.quest` do katalogu questów serwera (`docker/game/quest/` lub `locale/poland/quest/`), dodaj do `locale_list` i zrekompiluj questy przez `qc`.
