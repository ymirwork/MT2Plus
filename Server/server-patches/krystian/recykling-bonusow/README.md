# System Recyklingu Bonowanego Ekwipunku

System umożliwiający graczowi oddawanie u Dozorcy niepotrzebnych przedmiotów posiadających 5 bonusów w zamian za cenne materiały wzmacniające.

## Co daje graczowi
- Wymiana bezużytecznych przedmiotów z 5 bonusami u Dozorcy na:
  - Zaczarowania Przedmiotu (zmianki)
  - Wzmocnienia Przedmiotu (dodania)
- Zapobiega zaśmiecaniu rynku i ekwipunku bezwartościowymi dropami z 5 bonusami.

## Zawartość paczki
- `Server/linux-port/docker/game/quest/recykling_bonusow.quest` – logika questu u Dozorcy.
- `Klient/pack/root.data` i `root.index` – wsparcie klienta.
- Pliki konfiguracyjne i locale serwera.
